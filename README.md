# RUC thesisdown · 人大論文範本（規劃中）

**English** · [繁體中文](#繁體中文)

A planned bookdown template for doctoral dissertations at Renmin University of
China. **Template source files have not been published yet.** This repository
currently contains this status page only; it is not a usable dissertation template.

The repository was created on 2024-06-02 and remained empty until this status page
was added on 2026-11-10. No bookdown build or compliance check against current
university formatting requirements has been completed for this repository.

GitHub's **Use this template** setting is enabled for future development. At this
stage it copies the status page, not a working thesis project.

Available academic tooling is listed on [Ruipeng LU's profile](https://github.com/lzhs1995).
